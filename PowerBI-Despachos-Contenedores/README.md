# Análisis de Despachos de Contenedores

Dashboard desarrollado en **Power BI** para el análisis de información relacionada con despachos de contenedores.

## Objetivo

Analizar el comportamiento de los despachos considerando variables como:

- Ciudad de origen.
- Ciudad de destino.
- Transportador.
- Peso de los despachos.
- Costo de transporte.
- Número de contenedores.

## Herramientas

- Power BI
- Power Query
- DAX
- Google Cloud Storage
- GitHub

## Dashboard

El dashboard permite analizar los despachos mediante indicadores, gráficos, mapas y tablas de detalle.
